关键依赖规则： ① gui/ 不直接发网络请求，只消费 database.get_dashboard_snapshot() 与 event_queue； ② core/*_check.py 是纯函数，不 import GUI； ③ AlertEngine 与 MonitorEngine 通过 database 持久化告警状态，重启不丢失败计数； ④ daily_report.build_daily_report 不触发任何网络 IO，只拼装 Markdown。
